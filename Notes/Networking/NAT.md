# What is NAT ?
    NAT (Netowrk Address translator) is a method used by routers to
    all multiple devices on a same local private network to share a
    single pubplic IP address . it works by altering the IP address
    details in data packets as they travel back and forth ...

# why do home routers use NAT ?
    Routers use NAT to allow multiple devices to share a public ip
    which solves the ip4 address shortage ...secondly this provides
    security by not exposing the devices original ip address so that
    no one outside of the network can send any malicisous requests
    to the devices inside the network..
