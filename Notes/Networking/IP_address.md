# subnetmask
    Subnet mask is basically used to distinguish between the Network part from
    the device id that is connected to the network in an ip address ...
    for example ... if your ip is 10.97.211.14 and your subnet is 255.255.255.0 
    means your id is 14 and the 10.97.211 is the network part ... every segment 
    in a ip is 8 bits long... total of 32 bits ..subnet mask just tells us how many bits
    are used to represent network part ..
